КНОПКИ ПУЛЬТА — обучение кнопок для Android-магнитолы

Переназначает кнопки беспроводного пульта (и любые другие кнопки, которые видит Android):
короткое и долгое нажатие -> трек вперёд/назад, пауза, громкость, без звука, Домой, Назад,
недавние, шторка, запуск любого приложения или блокировка кнопки.

УСТАНОВКА
1. Скачать SwcLearn.apk из раздела Releases (последний релиз) и установить на магнитолу.
2. Открыть «Кнопки пульта» -> «Включить службу» -> включить «Кнопки пульта» в спец. возможностях.
3. «Добавить кнопку» -> нажать кнопку на пульте -> выбрать нажатие и действие.

Внизу экрана — журнал: какие коды кнопок видит Android. Если кнопка в журнале не появляется,
её обрабатывает сама магнитола (провода KEY1/KEY2) — настраивайте в «Настройках рулевого колеса».

СБОРКА: GitHub Actions (.github/workflows/build.yml) при каждом push в ветку swc-learn.
